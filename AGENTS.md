# AGENTS.md — инструкции по оформлению лабораторных работ (LaTeX)

Этот файл задаёт **обязательные** правила оформления документов на основе шаблона `labstyle.sty` (ННГУ, pdflatex).

Перед генерацией или правкой любого `.tex` файла **прочитай и соблюдай** все правила ниже.

---

## 0. Жёсткие ограничения

- **Не изменять** файл `labstyle.sty`.
- **Не изменять** структуру папки `source/`.
- Дополнительные пакеты и настройки добавлять **только** в преамбулу `main.tex` **после** строки `\usepackage{labstyle}`.
- Базовая преамбула:

```latex
\documentclass[14pt]{extarticle}
\usepackage{labstyle}
\begin{document}
```

Русский язык, математика (`amsmath`, `physics` и др.), графика, ссылки и прочее **уже** внутри `labstyle`. **Не** подключать повторно пакеты, которые уже есть в стиле (см. §10). Лишние пакеты без необходимости не добавлять.

### 0.1 АБСОЛЮТНЫЙ ЗАПРЕТ: `\(...\)`

**КРИТИЧЕСКОЕ ПРАВИЛО. НАРУШЕНИЕ НЕДОПУСТИМО.**

- Конструкция `\(...\)` **запрещена полностью и безоговорочно**.
- В этом шаблоне для inline-математики существует **ровно один** допустимый способ: `$...$`.
- `\(...\)` не использовать:
  - ни для символов,
  - ни для коротких формул,
  - ни «для красоты»,
  - ни «по привычке»,
  - ни «потому что так в других шаблонах».
- Если модель сгенерировала хотя бы одну пару `\(...\)` — ответ считается **бракованным**. Нужно немедленно переписать фрагмент на `$...$` и больше не повторять ошибку.
- Перед отправкой кода **обязана** проверить: в файле нет ни одной последовательности `\(` и `\)`.

Запомнить:

| Нужно | Запрещено навсегда |
|-------|--------------------|
| `$E = mc^2$` | `\ ( E = mc^2 \ )` (без пробелов: `\(...\)`) |
| `$v$` | `\ ( v \ )` |

Любая попытка использовать `\(...\)` — грубое нарушение этого файла.

## 1. Формулы

### 1.0 Выбор окружения

| Нумерация | По центру | Больше 1 строки | Окружение   | Правило |
|-----------|-----------|-----------------|-------------|---------|
| Да        | Да        | Нет             | `align`     | 1.1     |
| Да        | Да        | Да              | `multline`  | 1.2     |
| Нет       | Да        | Нет             | `\[ ... \]` | 1.3     |
| Нет       | Да        | Да              | `multline*` | 1.4     |
| Нет       | Нет       | любое           | `$...$`     | 1.5     |

**Запрещено:**
- `\(...\)` — **никогда, ни при каких условиях** (см. §0.1). Это не «нежелательно», это **запрет**;
- `equation`, `gather` и аналоги без явной необходимости;
- нумеровать формулы через `\[` или `$`.

---

### 1.1 Нумерованная, одна строка → `align`

```latex
\begin{align} \label{eq:th:1}
	E = mc^2
\end{align}
```

- `\label{...}` — **сразу после** `\begin{align}` через пробел, на той же строке.
- Одна формула — одна строка, без `\\`.
- Запятая/точка в конце формулы — внутри математики.

---

### 1.2 Нумерованная, несколько строк → `multline`

```latex
\begin{multline} \label{eq:th:2}
	E = mc^2
	=\\=
	\frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}
\end{multline}
```

- Перенос **только** на операторах: `+`, `-`, `*`, `=` и т.п.
- Оператор-разделитель оформлять как `=\\=`, `+\\+`, `-\\-` (на отдельной «логической» строке переноса).
- `\label{...}` — сразу после `\begin{multline}` на той же строке.
- Один номер на всё окружение.

---

### 1.3 Без номера, одна строка, по центру → `\[ ... \]`

```latex
\[
E = mc^2
\]
```

- `\[` и `\]` — на **отдельных** строках.
- Сама формула — на отдельной строке между ними.
- Без `\\`.

---

### 1.4 Без номера, несколько строк → `multline*`

```latex
\begin{multline*}
	E = mc^2
	=\\=
	\frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}
\end{multline*}
```

Правила переноса те же, что в 1.2.

---

### 1.5 В тексте (inline) → только `$...$`

```latex
где $E$ --- энергия, $m$ --- масса, $c$ --- скорость света.
```

- **Только** `$...$`.
- `\(...\)` — **запрещено** (см. §0.1). Повторять нельзя. «Случайно» тоже нельзя.
- Правило действует для:
  - простых символов (`$v$`, `$E$`, `$i$`);
  - коротких выражений;
  - любых inline-формул в абзаце.
- Если сомневаешься — пиши `$...$`, не `\(...\)`.
- Многострочные выражения в тексте тоже через `$...$` (не выносить в display без необходимости).

---

### 1.6 Системы и случаи

```latex
\begin{align*}
	i = \begin{cases}
		0 & \text{при } u \leqslant v_1 \\
		S(u - v_1) & \text{при } v \geqslant v_1
	\end{cases}.
\end{align*}
```

---

### 1.7 Индексы, производные, типографика в формулах

- Многобуквенные и русские индексы — только через `\text{...}`:  
  `$e_\text{г}$`, `$\omega_\text{г}$`, `$Z_\text{э}$`, `$R_\text{э}$`.
- Производные (пакет `physics`):  
  `\dv{y}{t}`, `\dv[n]{y}{t}`, `\dv[2]{i}{u}`.
- Нестрогие неравенства: `\leqslant`, `\geqslant`.
- Высокие скобки: `\Big[ ... \Big]`.
- Выделение результата: `\boxed{...}`.
- Разделение кусков в одной строке: `\qquad`.
- Русские слова в формулах: `\text{...}` (с нужными пробелами внутри).
- Многоточие в математике: `\dots`.
- Десятичная запятая в числах: пакет `icomma` уже подключён — в математике можно писать `$3,14$`.

## 2. Отступы вокруг формул

### 2.1 Обычный случай (формула разделяет текст)

```latex
Текст, подводящий к формуле:
\[
E = mc^2
\]

Продолжение текста...
```

- **Перед** выключной формулой пустой строки нет.
- **После** выключной формулы — одна пустая строка.
- Так сохраняется компактность и в коде, и в PDF.

### 2.2 Формула, после которой сразу пояснение в той же «логике»

Если дальше идёт связка вида «где $...$ --- ...», пустую строку после формулы **не ставить** (чтобы не было красной строки / лишнего абзацного отступа).

### 2.3 Несколько выключных формул подряд

Между ними **пустых строк не делать**:

```latex
\[
E = mc^2
\]
\[
F = ma
\]
```

То же для последовательности `align` / `multline` / `multline*`.

### 2.4 Общие правила пустых строк

- Пустая строка **после** каждого выключного окружения: `align`, `multline`, `multline*`, `\[...\]`, `figure`, `itemize`, `enumerate`, `tabbing` (если дальше идёт новый абзац).
- Между абзацами текста — одна пустая строка.
- Перед `\subsection` — пустая строка.
- Внутри окружений — один уровень табуляции (символ таб).

## 3. Метки `\label` и ссылки `\cref`

### 3.1 Схема именования

Формат: `тип:раздел:номер`

| Тип        | Префикс | Примеры                          |
|------------|---------|----------------------------------|
| Формула    | `eq:`   | `eq:th:1`, `eq:pr:3`, `eq:app:2` |
| Рисунок    | `fig:`  | `fig:th:1`, `fig:pr:2`           |
| Подрисунок | `fig:`  | `fig:th:1a`, `fig:th:1b`         |
| Таблица    | `tab:`  | `tab:pr:1`                       |

Разделы:
- `th` — теоретическая часть;
- `pr` — практическая часть / ход работы / результаты;
- `app` — приложение.

Номер — по порядку появления в соответствующем разделе.

### 3.2 Где ставить `\label`

- **Формула (`align` / `multline`):** сразу после `\begin{...}` на той же строке.
- **Рисунок:** после `\caption{...}`.
- **Подрусунок:** после соответствующего `\subcaption{...}`.

### 3.3 Ссылки

- Использовать **только** `\cref{...}`.
- **Никогда** не писать `\ref`, `\eqref`, а также вручную «рис.», «табл.», «уравнение» перед ссылкой — префиксы уже заданы в `labstyle`.

Примеры:

```latex
\cref{eq:th:1}
\cref{fig:pr:2}
\cref{eq:th:5,eq:th:6}   % несколько: через запятую, без пробелов
```

Настройки `cleveref` в стиле (для справки, не дублировать в документе):

```latex
\crefname{figure}{рис.}{рис.}
\Crefname{figure}{Рис.}{Рис.}
\crefname{table}{табл.}{табл.}
\Crefname{table}{Табл.}{Табл.}
\crefname{equation}{}{(}
\crefformat{equation}{(#2#1#3)}
```

## 4. Рисунки и графики

### 4.1 Один рисунок

```latex
\begin{figure}[H]
	\centering
	\includegraphics[width=0.5\linewidth]{graph_1}
	\caption{Подпись рисунка}
	\label{fig:pr:1}
\end{figure}
```

Правила:
- Позиция: по умолчанию `[H]`. Допустимы также `t`, `b`, `p`. Другие не использовать.
- `\centering` не убирать и не менять.
- `width=...\linewidth` подбирать так, чтобы рисунок читался и не занимал больше ~половины страницы. Типичные значения: `0.4`, `0.5`, `0.6`, `0.8`, `0.9`.
- `\caption{}` — если подписи нет, оставить пустым; иначе писать текст.
- `\label{...}` — **после** `\caption`.

### 4.2 Два рисунка в ряд (с подписями а, б)

```latex
\begin{figure}[H]
	\centering
	\begin{minipage}{0.45\textwidth}
		\centering
		\includegraphics[width=0.6\linewidth]{...a}
		\subcaption{...}
		\label{fig:th:1a}
	\end{minipage}
	\begin{minipage}{0.45\textwidth}
		\centering
		\includegraphics[width=0.9\linewidth]{...b}
		\subcaption{...}
		\label{fig:th:1b}
	\end{minipage}
	\caption{Общая подпись}
	\label{fig:th:1}
\end{figure}
```

- Подрусунки в `\label` с суффиксом буквы: `a`, `b`, `c`, ...
- Ширину `minipage` и `includegraphics` подбирать по ситуации.

## 5. Таблицы

В стиле уже подключены: `booktabs`, `longtable`, `multirow`, `multicol`.

Рекомендации:
- для простых таблиц — `tabular` + при необходимости `booktabs` (`\toprule`, `\midrule`, `\bottomrule`);
- для длинных — `longtable`;
- объединённые ячейки — `multirow` / `multicolumn`.

`\label{tab:...}` — после `\caption`.  
Ссылки — только `\cref{tab:...}`.

---

## 6. Списки

```latex
\begin{itemize}
	\item Первый пункт.
	\item Второй пункт.
\end{itemize}

\begin{enumerate}
	\item Первый пункт.
	\item Второй пункт.
\end{enumerate}
```

- Текст пункта — с заглавной буквы.
- Если пункт — полное предложение, в конце точка.
- Формулы внутри пунктов — по общим правилам (`$...$` или выключные).
- Отступы списков в стиле уже сжаты (`noitemsep`, малые `topsep`/`itemsep`) — **не** раздувать их вручную.
- На **втором** уровне `enumerate` метки — **кириллица** (`а)`, `б)`, …) через `asbuk`. Не заменять на латиницу вручную.

---

## 7. `tabbing` (формулы с пояснениями)

```latex
\begin{tabbing}
\hspace{10cm} \= \kill
$\displaystyle ...$ \> --- пояснение \\
$\displaystyle ...$ \> --- пояснение
\end{tabbing}
```

- `\hspace{10cm} \= \kill` задаёт ширину колонки.
- `\>` — разделитель колонок.
- Для «крупных» дробей в такой строке допустим `\displaystyle` **внутри** `$...$`.
- Снова: только `$...$`, никогда `\(...\)`.

## 8. Структура текста и команды стиля

- Акценты: `\textbf{Цель работы.}`, `\textbf{Назначение устройства.}`.
- `\section{...}` — в стиле: **римские** номера, **ВЕРХНИЙ РЕГИСТР**, по центру. Точку в конце названия не ставить.
- `\subsection{...}` — арабские номера (`1.`, `2.`, …), **без** точки в конце названия.
- `\subsubsection{...}` — `1.1`, `1.2`, …; без точки в конце названия.
- Перед `\subsection` / `\subsubsection` — пустая строка.

### 8.1 Приложения

Не использовать стандартный `\appendix` без нужды. В стиле есть своя команда:

```latex
\appendixsection{Название приложения}\label{app:1}
```

- Нумерация: «Приложение 1. …», «Приложение 2. …».
- Ссылки: `\cref{app:1}` → «прил. …» (настроено в `cleveref`).
- `\label` ставить сразу после `\appendixsection{...}`.

### 8.2 Метаданные в `main.tex` (колонтитулы и титул)

В преамбуле `main.tex` задаются макросы (их **не** дублировать в `labstyle.sty`):

```latex
\def\labtheme{Полное название лабораторной}
\def\shortlabtheme{Короткое название} % в колонтитул
\def\labauthors{Фамилия И.О., Фамилия И.О.}
\def\labgroupshort{438Б (...)}
\def\course{3 курса специалитета}
\def\studyprogram{...}
```

- `\labauthors` и `\shortlabtheme` попадают в **колонтитулы** (`fancyhdr`).
- При смене темы/авторов править **только** эти `\def` в `main.tex`.

### 8.3 Заметки / врезки

Окружение `note` (tcolorbox) уже в стиле:

```latex
\begin{note}
Текст важного замечания.
\end{note}
```

Серый фон, вертикальная полоса слева. Для обычных абзацев не злоупотреблять.

## 9. Типографика (текст)

| Нужно              | Писать          | Не писать      |
|--------------------|-----------------|----------------|
| Короткое тире      | `--`            | `-` (как тире) |
| Длинное тире       | `---`           |                |
| Многоточие в тексте| `...`           |                |
| Многоточие в матем.| `\dots`         |                |

В тексте лабораторной для тире предпочтительно `--` или `---` по смыслу (диапазон / тире в предложении).

## 10. Возможности `labstyle.sty` (не дублировать в документе)

Всё перечисленное **уже** загружено стилем. Повторный `\usepackage{...}` тех же пакетов не нужен и может сломать сборку.

### 10.1 Уже подключённые пакеты (кратко)

| Область | Пакеты |
|---------|--------|
| Страница | `geometry` (A4: лев. 2 cm, прав. 1 cm, верх/низ 1 cm) |
| Текст / язык | `cmap`, `setspace`, `ulem` (`normalem`), `indentfirst`, `microtype`, `fontenc` T2A, `inputenc` utf8, `babel` english+russian |
| Таблицы | `multirow`, `multicol`, `longtable`, `booktabs` |
| Математика | `amsmath`, `amssymb`, `amsfonts`, `mathtools`, `icomma`, `mathgreeks`, **`physics`** |
| Рисунки | `graphicx`, `placeins`, `wrapfig`, `float`, `caption`, `subcaption` |
| Графика | `tikz`, `circuitikz`, `pgfplots`, `tcolorbox` |
| Ссылки | `xurl`, `hyperref`, `cleveref` (russian, capitalize) |
| Прочее | `enumitem`, `fancyhdr` |

**Не** подключать `physics`, `amsmath`, `graphicx`, `hyperref`, `cleveref` и т.д. повторно в `main.tex`.

### 10.2 Пути к изображениям

```latex
\graphicspath{{image/}{graph/}}
```

Файлы класть в `image/` или `graph/` (относительно корня проекта / каталога компиляции). В `\includegraphics` писать **имя без пути**, если файл лежит в одной из этих папок:

```latex
\includegraphics[width=0.5\linewidth]{graph_1}
```

### 10.3 Подписи рисунков (уже настроено)

- Имя: «Рис.»
- Разделитель: точка (`Рис. 1. Текст`)
- Шрифт подписи: `small`, метка — полужирная
- Выравнивание: по центру
- Позиция подписи: снизу

Вручную «Рис.» перед `\caption` **не** писать.

### 10.4 Математические операторы и символы стиля

```latex
\re      % Re
\im      % Im
\Div     % div
\Rot     % rot
\Grad    % grad

\E       % \mathcal{E}
\A       % \mathcal{A}
\R       % \mathcal{R}
```

- `\epsilon` в этом стиле **сразу** означает `\varepsilon` (переопределено через `\let\epsilon\varepsilon`). Не плодить лишние `\varepsilon`, если достаточно `\epsilon`.

Производные — через уже подключённый `physics`: `\dv{y}{t}`, `\dv[2]{i}{u}` и т.д.

### 10.5 Ссылки `cleveref` (уже настроено)

| Счётчик | `\cref` | `\Cref` |
|---------|---------|---------|
| figure | рис. | Рис. |
| table | табл. | Табл. |
| appsection | прил. | Прил. |
| listing | лист. | Лист. |
| equation | `(номер)` без слова «уравнение» | — |

Формулы: `\cref{eq:th:1}` → `(1)` (формат задан в стиле).  
Несколько формул: `\cref{eq:th:1,eq:th:2}` → вида `(1) и (2)`.

### 10.6 Чего не делать из‑за стиля

- Не менять `\geometry`, `\linespread`, отступы display-формул — они уже заданы (в т.ч. малые `\abovedisplayskip` / `\belowdisplayskip`).
- Не переопределять `\section` / `\subsection`.
- Не подключать второй раз `babel`, `fontenc`, `inputenc`.
- Не писать вручную «рис.» / «табл.» рядом с `\cref`.
- Не класть картинки вне `image/` и `graph/` без явной необходимости (иначе править путь).

### 10.7 Структура файлов проекта (ориентир)

```text
main.tex                 % преамбула + \include
labstyle.sty             % НЕ ТРОГАТЬ
source/
  title.tex
  content.tex
  introduction.tex
  theory.tex
  practise.tex
  conclusion.tex
  questions.tex
  appendix.tex
image/  или graph/       % рисунки
```

Новые разделы — новые файлы в `source/` + `\include{...}` в `main.tex`. Иерархию `source/` не ломать.

## 11. Шаблоны для копирования

**Нумерованная короткая формула:**

```latex
\begin{align} \label{eq:th:N}
	... = ...
\end{align}
```

**Нумерованная длинная:**

```latex
\begin{multline} \label{eq:th:N}
	...
	=\\=
	...
	=\\=
	...
\end{multline}
```

**Без номера, одна строка:**

```latex
\[
...
\]
```

**Без номера, несколько строк:**

```latex
\begin{multline*}
	...
	=\\=
	...
\end{multline*}
```

**Рисунок:**

```latex
\begin{figure}[H]
	\centering
	\includegraphics[width=0.5\linewidth]{имя_файла}
	\caption{...}
	\label{fig:pr:N}
\end{figure}
```

**Ссылки:**

```latex
